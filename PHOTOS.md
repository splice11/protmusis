# Photos — status

All photos have been collected, renamed, and converted to standard formats
(JPEG for photographs, PNG for flat artwork; descriptive snake_case names).
They live in `photos/` and are wired into both question and answer slides
by `generate_slides.py` — the second upload batch replaced most of the
remaining icon placeholders with real images, including the Umaru Dikko
crate press photo.

See **[photos/CREDITS.md](photos/CREDITS.md)** for what each file shows,
which slide uses it, and the reconstructed attribution — including the
items still marked *to confirm*.
